Daily Living Calendar Management▾
Pleaides’ scheduling calendar allows tasks to be assigned, accepted and viewed by others based on permissions you create. For each task, specify where help is needed, and should be assigned and/or viewed by others. Tasks can be organized by each care member’s location, so tasks are appropriately assigned (example: someone in another state cannot be assigned driving tasks).
